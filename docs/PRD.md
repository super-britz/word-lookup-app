# Word Lookup App - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
Word Lookup App（查词应用）

### 1.2 产品定位
一款面向中文用户的移动端英语单词学习应用，主打词源探索与科学记忆，帮助用户高效记忆英语单词。

### 1.3 技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18.3.1 | UI 框架 |
| TypeScript | 5.3.3 | 类型安全 |
| Vite | 5.1.4 | 构建工具 |
| Tailwind CSS | 3.4.1 | 样式方案 |
| React Router | 6.22.0 | 路由管理 |
| Zustand | 4.5.7 | 状态管理 |
| Lucide React | 0.563.0 | 图标库 |

### 1.4 目标用户
- 英语学习者（中文母语）
- 前端开发求职者
- 日常英语交流学习者
- 影视美剧爱好者

## 2. 功能模块

### 2.1 页面路由结构

| 路由 | 页面 | 功能 |
|------|------|------|
| `/` | 首页 (HomePage) | 搜索、推荐词单、学习统计、查词历史 |
| `/search` | 查词结果页 (SearchResultPage) | 展示单词详细信息 |
| `/word/:id` | 单词详情页 (WordDetailPage) | 闪卡学习模式 |
| `/vocabulary` | 生词本 (VocabularyPage) | 收藏单词管理 |
| `/review` | 复习页 (ReviewPage) | 复习计划与进度追踪 |
| `/settings` | 设置页 (SettingsPage) | 用户设置与数据管理 |
| `/welcome` | 欢迎页 (WelcomePage) | 新用户引导 |
| `/import` | 导入页 (ImportPage) | 批量导入单词 |

---

### 2.2 首页 (HomePage)

**功能点：**
- **搜索栏**：输入单词后跳转到查词结果页，支持语音搜索（预留）
- **推荐词单**：展示三个分类标签（前端求职、日常交流、影视美剧），点击切换
- **今日学习统计卡片**：显示当前已学/目标单词数，含进度条
- **查词历史列表**：最近 20 条查词记录，支持一键清空（需确认），支持加入生词本
- **底部导航栏**：首页、生词本、复习、设置四个 Tab

### 2.3 查词结果页 (SearchResultPage)

**功能点：**
- 展示单词名称、音标、中文释义、英文定义、词源、例句
- "加入生词本"按钮：将单词添加到生词本，同时更新今日学习统计
- "详细学习"按钮：跳转到闪卡学习模式
- 发音按钮（预留）

### 2.4 单词详情页 (WordDetailPage)

**功能点：**
- 闪卡正面：显示单词和音标
- 闪卡背面：显示释义、定义、例句（点击"显示答案"翻转）
- 自我评估：不会（红）、模糊（黄）、掌握（绿）三个按钮
- 复习次数显示

### 2.5 生词本 (VocabularyPage)

**功能点：**
- 统计栏：总词数、已复习、待复习
- 单词卡片列表：彩色首字母头像、音标、释义、添加时间、复习次数徽章
- 删除单词（Trash 图标，点击后 Toast 提示）
- 搜索按钮（预留）、导出按钮（预留）
- 空状态引导：引导用户去查词

### 2.6 复习页 (ReviewPage)

**功能点：**
- 今日复习进度卡片：进度条 + 百分比 + "继续复习"按钮
- 复习记录列表：展示近期复习历史（完成/进行中/部分完成）
- 学习统计：连续天数、总单词数、掌握率

### 2.7 设置页 (SettingsPage)

**功能点：**
- 用户资料展示（头像、姓名、邮箱、统计数据）
- 每日学习目标设置（输入框实时更新）
- 发音开关、自动播放发音开关（预留）
- 导入单词（跳转导入页）、导出数据（预留）
- 清空历史记录（需二次确认）
- 版本信息

### 2.8 欢迎页 (WelcomePage)

**功能点：**
- 三步引导轮播：探索词源 → 科学记忆 → 追踪进度
- 步骤指示器、下一步按钮、跳过按钮
- 最后一步显示"开始使用"

### 2.9 导入页 (ImportPage)

**功能点：**
- 粘贴文本导入（每行一个单词）
- 实时单词计数
- 格式说明提示
- 上传文件导入（预留）

## 3. 数据模型

### 3.1 Word（单词）

```typescript
interface Word {
  id: string              // 唯一标识
  word: string            // 英文单词
  phonetic: string        // 音标
  translation: string     // 中文翻译
  definition: string      // 英文定义
  etymology?: string      // 词源（可选）
  examples: string[]      // 例句数组
  addedAt: string         // 添加时间
  reviewCount: number     // 复习次数
  lastReviewed?: string   // 上次复习时间（可选）
  inVocabulary: boolean   // 是否在生词本中
}
```

### 3.2 WordList（词单）

```typescript
interface WordList {
  id: string       // 词单 ID
  name: string     // 词单名称
  icon: string     // 图标标识
  words: Word[]    // 词单包含的单词
}
```

### 3.3 UserStats（用户统计）

```typescript
interface UserStats {
  todayLearned: number   // 今日已学
  dailyGoal: number      // 每日目标
  totalWords: number     // 总单词数
  streak: number         // 连续学习天数
}
```

## 4. 用户故事

### 4.1 核心流程

| 编号 | 用户故事 | 验收标准 |
|------|---------|---------|
| US-01 | 作为用户，我想搜索一个英文单词，以查看它的释义和词源 | 输入单词后跳转到结果页，展示完整信息 |
| US-02 | 作为用户，我想将单词加入生词本，以便后续复习 | 点击按钮后单词出现在生词本列表中 |
| US-03 | 作为用户，我想在生词本中查看和管理我的单词 | 能看到所有收藏的单词并可以删除 |
| US-04 | 作为用户，我想通过闪卡模式复习单词 | 正面显示单词，翻转后显示释义 |
| US-05 | 作为用户，我想查看我的学习统计数据 | 首页和复习页展示进度和统计 |
| US-06 | 作为用户，我想设置每日学习目标 | 在设置页修改目标后即时生效 |
| US-07 | 作为用户，我想清空查词历史 | 确认后清空所有历史记录 |
| US-08 | 作为用户，我想批量导入单词 | 粘贴单词列表后点击导入 |

### 4.2 页面导航流程

```
欢迎页 → 首页 → 搜索结果页 → 单词详情页
                ↕                    ↓
           生词本页              复习页
                ↕
           设置页 → 导入页
```

## 5. 状态管理

### 5.1 全局状态（Zustand + localStorage 持久化）

**状态项：**
- `userStats` - 用户学习统计
- `searchHistory` - 查词历史（最多 20 条）
- `vocabulary` - 生词本单词列表
- `wordLists` - 推荐词单分类
- `currentTab` - 当前导航 Tab
- `searchQuery` - 搜索关键词

**操作方法：**
- `addToHistory(word)` - 添加查词记录
- `addToVocabulary(word)` - 加入生词本
- `removeFromVocabulary(wordId)` - 移出生词本
- `clearHistory()` - 清空历史
- `updateStats(stats)` - 更新统计
- `incrementTodayLearned()` - 今日学习数 +1

### 5.2 持久化策略
- 使用 `zustand/middleware` 的 `persist` 中间件
- 存储 Key：`word-app-storage`
- 存储位置：浏览器 localStorage

## 6. 设计规范

### 6.1 布局
- 移动端优先，最大宽度 375px（iPhone 设计稿基准）
- 固定高度 1200px（模拟手机屏幕）
- 底部导航固定定位

### 6.2 色彩体系
| 用途 | 颜色值 |

| 主色 Primary | `#2463eb` |
| 背景色 | `#f6f6f8` |
